14. 你现在可以把整个知识点压缩成这一张图

最核心的一句话就是：

在 ARM64 上，程序使用的是虚拟地址。MMU 首先使用 VA + ASID 查询 TLB；TLB 命中就直接得到物理页信息；TLB 未命中时，MMU 根据 TTBR0_EL1 指向的页表根节点进行硬件 page-table walk，逐级查询 L0/L1/L2/L3，最终从页表项得到物理页框，再加上虚拟地址中保持不变的 page offset，形成最终物理地址 PA。

而且要特别区分：

TLB miss + 页表有效 → MMU 自己解决。

页表项无效/权限不允许 → CPU exception → Linux page fault 处

概念 本质 通常在哪里
MMU 地址转换硬件 CPU 内部
TLB / 快表 地址转换缓存 CPU/MMU 内部
PTBR 页表根地址寄存器 CPU 内部
页表 地址映射数据结构 DDR 内存
多级页表 分层组织的页表 DDR 内存
PTE 单个页表项 页表中
