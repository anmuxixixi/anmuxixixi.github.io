dm-dust学习笔记

理论部分

dm-dust 是 Linux Device Mapper 的一个测试 target，用于在指定逻辑块上模拟坏块。

它在一个真实块设备或 loop 设备上套一层虚拟块设备：

它主要模拟机械硬盘常见的坏扇区行为：

  • 指定位置的读取返回 EIO/Input/output error。
  • 对坏块进行覆盖写后，写入成功，同时该块从坏块表中移除。
  • 这类似硬盘固件在写入坏扇区时进行扇区重映射。

不过它并不真的破坏底层设备，也不真的修改硬盘坏块表；坏块列表只存在于内核内存中，删除 dm 设备后就消失。内核官方文档明确描述了这种读取失败、写入后“修复”的模型。内核 dm-dust 文档

dm-dust映射表

典型的dm-dust表：

字段 含义
0 DM 逻辑设备的起始扇区
32768 DM 设备长度，单位固定为 512 字节扇区
dust 使用 dm-dust target
/dev/loop0 底层块设备
0 映射到底层设备的起始扇区
512 dm-dust 坏块粒度 blksz
