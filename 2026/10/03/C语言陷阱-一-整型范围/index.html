无符号整型回绕

❗❗❗无符号整型的回绕跟C语言的标准有关

在 C11 / ISO/IEC 9899:2011，§6.2.5 “Types”，第 9 段，原文是：

A computation involving unsigned operands can never overflow, because a result that cannot be represented by the resulting unsigned integer type is reduced modulo the number that is one greater than the largest value that can be represented by the resulting type.

意思就是：

无符号类型参与的计算不会发生 C 标准意义上的 overflow；如果数学结果超出该无符号类型能表示的范围，就对“该类型最大值 + 1”取模。

隐式转换陷阱

  1. 赋值表达式中，将右边的值转换为左边的类型，然后赋值给左边的变量。
  1. 算术运算式中，低类型能够转换为高类型。
  1. 函数调用时，将实参转换为形参的类型。
  1. 逻辑运算式中，将非布尔类型转换为布尔类型。
  1. 如果表达式中既有 int 又有 unsigned int ，则所有的 int 数据都被转化为 unsigned int 类型

当 int 和 unsigned int 作为需要进行 usual arithmetic conversions 的两个操作数时，因为它们的 integer conversion rank 相同，所以 int 操作数会转换成 unsigned int。

https://www.open-std.org/jtc1/sc22/wg14/www/docs/n843.htm?
