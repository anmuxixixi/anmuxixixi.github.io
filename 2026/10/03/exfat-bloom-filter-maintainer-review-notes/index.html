过滤器在目录达到 1024 个磁盘目录项时建立。短名称通常占 3 个目录项，门槛附近大约只有：

Patch set 演进总结

Patch set Maintainer/Reviewer 关注点 主要修改
v1 单个 patch 过大，功能和错误路径混在一起 规划拆分为 Bloom filter、hint、shrinker 三个 patch
v2 free_inode() 可能在 RCU softirq context 执行 把过滤器释放移动到 evict_inode()
v3 255 UTF-16 边界错误；删除后 hint 不回退；系列需要拆分 修正长度判断；所有释放目录项路径失效 hint；拆成 3 patches
v4 hint 在提交前发布；rename/move 失败可能留下目标名称 成功提交后才发布 hint；失败时释放目标过滤器
v5 必须基于 dev；返回值判断错误；3-entry 空洞可能被 4-entry hint 跳过 rebase；使用 ret >= 0；增加 min_entries
v6 create 提交失败也可能写入名称；patch 必须独立正确 写失败立即释放过滤器；rename/move 失效逻辑放入 PATCH 1
v7 64 KiB 固定大小不合理；删除导致饱和；shrinker 可能无进展循环 动态 bitmap；饱和重建；按页统计；保留 scan budget/返回 SHRINK_STOP
